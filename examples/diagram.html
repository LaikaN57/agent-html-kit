Components

Component | Kind | Role Web app | Client | Browser client Mobile app | Client | Mobile client API gateway | Service | Entry point for both clients Checkout service | Service | Coordinates the checkout Cart service | Service | Loads carts, backed by Redis Payment service | Service | Charges the card through Stripe Fraud service | Service | Returns a fraud score Email service | Service | Consumes `order.created` and sends the receipt Postgres | Database | Orders database Redis | Cache | Cart cache Kafka | Event bus | Carries `order.created` Stripe | External | External payment provider

Diagram

Web app [user] -> API gateway [svc]: HTTPS Mobile app [user] -> API gateway [svc]: HTTPS API gateway [svc] -> Checkout service [svc]: gRPC Checkout service [svc] -> Cart service [svc]: gRPC, loads the cart Cart service [svc] -> Redis [cache]: reads and writes carts Checkout service [svc] -> Fraud service [svc]: asks for a fraud score Checkout service [svc] -> Payment service [svc]: charges the card Payment service [svc] -> Stripe [ext]: payment API call Checkout service [svc] -> Postgres [db]: writes the order Checkout service [svc] -> Kafka [queue]: publishes order.created Kafka [queue] -> Email service [svc]: consumes order.created, sends receipt

Walkthrough: one checkout

Client request | The Web app or Mobile app calls the API gateway over HTTPS Route to checkout | The API gateway forwards the request to the Checkout service over gRPC Load the cart | The Checkout service calls the Cart service over gRPC; the Cart service reads the cart from Redis Fraud check | The Checkout service asks the Fraud service for a fraud score Charge the card | The Checkout service asks the Payment service to charge the card; the Payment service makes the payment API call to Stripe Write the order | Only after the fraud score passes and the charge succeeds, the Checkout service writes the order to Postgres Publish event | The Checkout service publishes `order.created` to Kafka Send receipt | The Email service consumes `order.created` from Kafka and sends the receipt An order is only written to Postgres after the fraud score passes **and** the charge succeeds.
