Sequence

Client [user] -> API: POST /pay API -> Fraud service: score(order) Fraud service --> API: score 12, pass API -> Payments: charge(card, 42.00 USD) Payments -> Stripe [ext]: create PaymentIntent Stripe --> Payments: succeeded Payments -> Payments: store idempotency key note: The order is only written after the charge succeeds API -> Postgres [db]: INSERT order API -> Kafka [queue]: publish order.created API --> Client: 201 Created A retried POST /pay reuses the idempotency key, so Stripe never charges twice.
