1. Contract

Create a module **pricing.py** with exactly one public function:

`quote(cart, region, coupon=None, member=False) -> dict`

Parameter | Type | Meaning cart | list of dict | Each item has keys `sku` (str), `price` (int, cents, per unit), `qty` (int), `category` (str). Can be an empty list. region | str | Must be exactly `"US"`, `"EU"` or `"UK"`. This check is case-sensitive. coupon | str or None | Optional coupon code. `None` means no coupon. The code is case-insensitive, and surrounding whitespace is ignored. member | bool | Whether the customer is a member. The default is `False`.

The function returns a dict with **exactly** these five keys, all plain Python `int` values in cents and no other keys: `subtotal`, `discount`, `shipping`, `tax`, `total`.

All inputs and outputs are integer cents. Do not use float at any point, including for percentages. Use the integer half-up helper described in section 5. Do not use Python's built-in round(), because it does banker's rounding: round(234.5) gives 234, but we need 235.

2. Calculation flow

Caller [user] -> Validate region: cart, region, coupon, member Validate region -> Error [ext]: region not US/EU/UK, raise "unsupported region" Validate region -> Validate qty: region ok Validate qty -> Error [ext]: any item qty below 1, raise "invalid qty" Validate qty -> Empty cart check: all qty ok Empty cart check -> Result [db]: cart empty, return all five as 0 Empty cart check -> Subtotal [svc]: cart non-empty Subtotal [svc] -> Eligible amount [svc]: sum price*qty, all items Eligible amount [svc] -> Coupon discount [svc]: sum price*qty, non gift-card items Coupon discount [svc] -> Error [ext]: unknown code, raise "unknown coupon" Coupon discount [svc] -> Member discount [svc]: SAVE10 / FLAT500 / none Member discount [svc] -> Shipping [svc]: discount = coupon + member Shipping [svc] -> Tax [svc]: free, 599 or 899 Tax [svc] -> Total [svc]: rate on eligible - discount + shipping Total [svc] -> Result [db]: subtotal - discount + shipping + tax

3. Rules

3.1 Validation (always first, in this order)

Run validation before any other logic, and before the empty-cart shortcut. Check the region first, then the items. The first failure raises its error.

Order | Condition | Raise 1 | `region` is not one of `"US"`, `"EU"`, `"UK"` (exact, case-sensitive match, so `"us"` fails) | `ValueError("unsupported region")` 2 | Any item in the cart has `qty < 1` (check every item) | `ValueError("invalid qty")`

Error messages must match these strings exactly, with no extra text.

3.2 Empty cart

If validation passes and the cart is empty, return `{"subtotal": 0, "discount": 0, "shipping": 0, "tax": 0, "total": 0}`. An empty cart is **not** charged shipping.

3.3 Subtotal and eligible amount

Value | Definition subtotal | Sum of `price * qty` over **all** items, gift cards included eligible | Sum of `price * qty` over items whose `category != "gift-card"`

Gift cards (category exactly `"gift-card"`) count toward the subtotal and toward the free-shipping threshold. They are never discounted and never taxed.

3.4 Coupon discount

Normalise the code with `coupon.strip().upper()`. Only do this when `coupon is not None`.

Normalised code | Coupon discount | Condition (coupon is None) | 0 | No coupon applied SAVE10 | half_up(eligible × 10 / 100) | Always applies; is 0 if eligible is 0 FLAT500 | 500 | Only when eligible ≥ 3000; otherwise 0, and no error is raised anything else | (none) | Raise `ValueError("unknown coupon")`

Examples of valid inputs: `"save10"`, `" Save10 "`, `"\tflat500\n"`. Examples of inputs that raise "unknown coupon": `""`, `" "`, `"SAVE 10"`, `"SAVE5"`.

3.5 Member discount

member | Member discount False | 0 True | half_up((eligible − coupon_discount) × 5 / 100)

The member discount is applied after the coupon and uses the eligible amount minus the coupon discount as its base. The returned **discount** is `coupon_discount + member_discount`. Gift cards are never part of either base.

3.6 Shipping

Condition (check in this order) | Shipping member is True | 0 subtotal − discount ≥ 5000 | 0 region US | 599 region EU | 899 region UK | 899

Note that the threshold uses the **subtotal** (gift cards included), not the eligible amount, and the comparison is **≥**, so exactly 5000 qualifies.

3.7 Tax

Region | Tax rate US | 7 % EU | 20 % UK | 20 %

Compute `tax_base = eligible − discount + shipping`, then `tax = half_up(tax_base × rate / 100)`. Shipping is taxed. Gift cards are excluded because the base starts from the eligible amount. This means a gift-card-only cart that pays shipping still pays tax on the shipping.

3.8 Total

`total = subtotal − discount + shipping + tax`.

4. Constants

Name | Value SUPPORTED_REGIONS | US, EU, UK SHIPPING_FEE | US: 599, EU: 899, UK: 899 TAX_RATE_PERCENT | US: 7, EU: 20, UK: 20 FREE_SHIPPING_THRESHOLD | 5000 GIFT_CARD_CATEGORY | gift-card SAVE10_PERCENT | 10 FLAT500_AMOUNT | 500 FLAT500_MIN_ELIGIBLE | 3000 MEMBER_PERCENT | 5

5. Rounding rule

Every percentage result is rounded half up to a whole cent at the moment it is computed. This applies to three values: the SAVE10 discount, the member discount and the tax. Do not carry fractions forward to later steps. Each rounded value is used as-is in the steps that follow.

Implement this as a private integer helper: `_pct_half_up(amount, percent) = (amount * percent + 50) // 100`. All bases are non-negative for valid carts, so this formula is exact half-up. It uses no float and no `round()`.

Input | Exact value | half_up | Python round() (wrong) 2345 × 10% | 234.5 | 235 | 234 2110 × 5% | 105.5 | 106 | 106 3099 × 7% | 216.93 | 217 | 217 2004 × 20% | 400.8 | 401 | 401 50 × 5% | 2.5 | 3 | 2

If any item qty is below 1, raise ValueError("invalid qty"). Empty cart shortcut | If the cart is empty, return the five keys, all set to 0. 7. Worked examples

Items are written as `price × qty (category)`. All amounts are in cents.

# | Inputs | subtotal | eligible | discount | shipping | tax | total E1 | US, no coupon, non-member; 1000×2 (general), 500×1 (general) | 2500 | 2500 | 0 | 599 | 217 | 3316 E2 | EU, coupon "SAVE10", member; 2345×1 (apparel), 5000×1 (gift-card) | 7345 | 2345 | 341 | 0 | 401 | 7405 E3 | UK, coupon " flat500 ", non-member; 1500×2 (books) | 3000 | 3000 | 500 | 899 | 680 | 4079 E4 | US, coupon "FLAT500", non-member; 2999×1 (books) | 2999 | 2999 | 0 | 599 | 252 | 3850 E5 | US, coupon "SAVE10", non-member; 5556×1 (general) | 5556 | 5556 | 556 | 0 | 350 | 5350 E6 | US, no coupon, non-member; 5000×1 (gift-card) | 5000 | 0 | 0 | 0 | 0 | 5000 E7 | US, no coupon, non-member; 1000×1 (gift-card) | 1000 | 0 | 0 | 599 | 42 | 1641 E8 | EU, empty cart, any member value | 0 | 0 | 0 | 0 | 0 | 0

Derivations

  • **E1**: There is no discount. 2500 is below 5000, so shipping is the US fee of 599. Tax base is 2500 + 599 = 3099. 7% of 3099 is 216.93, which rounds to 217. Total is 2500 + 599 + 217 = 3316.
  • **E2**: SAVE10 on 2345 gives 234.5, which rounds half up to **235** (Python's round() would give 234). The member base is 2345 − 235 = 2110. 5% of 2110 is 105.5, which rounds to 106. Discount is 235 + 106 = 341. Shipping is free because the customer is a member. Tax base is 2345 − 341 + 0 = 2004. 20% of 2004 is 400.8, which rounds to 401. Total is 7345 − 341 + 0 + 401 = 7405. The gift card is never discounted or taxed.
  • **E3**: The coupon " flat500 " normalises to FLAT500. Eligible is 3000, which meets the ≥ 3000 condition, so the discount is 500. Subtotal minus discount is 2500, below 5000, so UK shipping of 899 applies. Tax base is 3000 − 500 + 899 = 3399. 20% of 3399 is 679.8, which rounds to 680. Total is 3000 − 500 + 899 + 680 = 4079.
  • **E4**: Eligible is 2999, below 3000, so FLAT500 gives 0 and raises no error. Shipping is 599. Tax base is 2999 + 599 = 3598. 7% of 3598 is 251.86, which rounds to 252. Total is 3850.
  • **E5**: SAVE10 on 5556 gives 555.6, which rounds to 556. Subtotal minus discount is exactly 5000, which meets the ≥ threshold, so shipping is free. Tax base is 5000. 7% of 5000 is 350. Total is 5556 − 556 + 0 + 350 = 5350.
  • **E6**: The cart holds only a gift card. Subtotal minus discount is 5000, so shipping is free. Tax base is 0 − 0 + 0 = 0, so tax is 0. Total is 5000.
  • **E7**: The cart holds only a gift card. Subtotal minus discount is 1000, below 5000, so shipping is 599. Tax base is 0 − 0 + 599 = 599. 7% of 599 is 41.93, which rounds to 42. Total is 1000 + 599 + 42 = 1641. Shipping is taxed even though the goods are not.
  • **E8**: Validation passes, so the empty-cart shortcut returns all five values as 0. No shipping is charged.
