Walkthrough: one checkout

Step through a single checkout. Each step highlights the connections it uses in the diagram above.

No step selected
  1. Customer submits checkout The customer checks out from the Web app (browser) or the Mobile app. Either client calls the API gateway over HTTPS.
  2. Gateway routes to Checkout service The API gateway forwards the request to the Checkout service over gRPC. The Checkout service drives the remaining steps.
  3. Load the cart The Checkout service loads the cart from the Cart service over gRPC. The Cart service reads and writes carts in Redis (the cart cache).
  4. Get a fraud score The Checkout service asks the Fraud service for a fraud score. The score must pass for the order to be written.
  5. Charge the card The Checkout service asks the Payment service to charge the card. The Payment service makes a payment API call to Stripe (external payment provider). The charge must succeed for the order to be written.
  6. Write the order (gated) Only if the fraud score passed and the charge succeeded does the Checkout service write the order to Postgres (the orders database).
  7. Publish order.created The Checkout service publishes an order.created event to Kafka (the event bus).
  8. Send the receipt The Email service consumes order.created from Kafka and sends the receipt.
